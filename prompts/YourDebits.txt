Prompt 01:
Crie um projeto do tipo WebApi com o nome "YourDebits" no diretório "./src/YourDebits" 
Inicie esse projeto APENAS com um endpoint simples que retorne "Hello World"

Prompt 02:
Adicione um novo model para o projeto "YourDebits" com o nome "Debit", dentro da pasta "Models".
O modelo deve ter as propriedades:
    Id: Guid
    Type: (Enum com os valores IPVA, MULTA, LICENCIAMENTO)
    Amount: decimal
    DueDate: DateTime (no formato "yyyy-MM-dd")
    Vehicle: string

O Enum deverá ficar na pastar "Enums"

Prompt 03:
Crie o endpoint para listagem dos débitos de um veículo. 
rota: /api/vehicle/{vehicleId}/debits
retorno de exemplo:
```json
{
  "vehicle": "ABC1234",
  "debts": [
    { "type": "IPVA",  "amount": 1500.00, "due_date": "2024-01-10" },
    { "type": "MULTA", "amount":  300.50, "due_date": "2024-02-15" }
  ]
}
```

Prompt 04: 
Crie um reposítório para o modelo "Debit", dentro da pasta "Repositories". Esse repositório guardaram dados de débitos veículares em memória.
Gere um seed com 3 débitos para a placa "ABC1234" (Propriedade "Vehicle" do modelo "Debit").
1. IPVA - 1500,00
2. MULTA - 300,50
3. LICENCIAMENTO - 1000,00

Prompt 05:
Implemente uma simples validação para o endpoint /api/vehicle/{vehicleId}/debits. Esse endpoint deve esperar um parâmetro via header "Authorization". Caso o valor esteja incorreto, retorne um erro 401.

Prompt 06:
Encapsule a lógica de validação do header em um middleware.
